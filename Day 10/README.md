## 📁 প্রজেক্ট আর্কিটেকচার ও ফাইল বিন্যাস (Directory Structure)

প্রজেক্টের ফ্রন্টএন্ড এবং ব্যাকএন্ড সম্পূর্ণ আলাদা ফাইল ও ডিরেক্টরিতে সুবিন্যস্ত করা হয়েছে:

```text
nasa/
├── backend/                              <-- সম্পূর্ণ ব্যাকএন্ড সিস্টেম (Node.js + Express + TypeScript)
│   ├── src/
│   │   ├── config/                       <-- সার্ভার ও এপিআই কনফিগারেশন
│   │   ├── types/                        <-- TypeScript টাইপ ডেফিনিশন
│   │   ├── ingestion/                    <-- নাসা, সয়েলগ্রিডস ও বিএআরসি উপাত্ত পাইপলাইন
│   │   │   ├── soilgrids.ts              <-- ISRIC SoilGrids v2 & USDA মাটির টেক্সচার ম্যাথ
│   │   │   ├── barc-aez.ts               <-- বাংলাদেশের ৩০টি কৃষি পরিবেশ অঞ্চল (AEZ) ও জেলাভিত্তিক উপাত্ত
│   │   │   ├── nasa-power.ts             <-- NASA POWER অ্যাগ্রোক্লাইমেটোলজি ও GDD হিসাব
│   │   │   ├── smap-openmeteo.ts         <-- NASA SMAP মূলমণ্ডল আর্দ্রতা (10-40cm) ও CWSI
│   │   │   ├── satellite-weather.ts      <-- উপগ্রহ আবহাওয়া ও বিপদ সতর্কতা পাইপলাইন
│   │   │   └── cache.ts                  <-- ৬ ঘণ্টার মেমোরি ক্যাশিং সিস্টেম
│   │   ├── engines/                      <-- ৪টি মূল এগ্রিকালচারাল এআই ইঞ্জিন
│   │   │   ├── mcda-recommendation.ts    <-- ইঞ্জিন ১: এক্সপ্লেইনেবল ফসল সুপারিশ (MCDA XAI)
│   │   │   ├── nitrogen-rotation.ts      <-- ইঞ্জিন ২ ও ৪: নাইট্রোজেন কার্ভ ও নাসা কাউন্টারফ্যাকচুয়াল অডিট
│   │   │   └── climate-hazard.ts         <-- ইঞ্জিন ৩: চরম আবহাওয়া আগাম সতর্কতা ইঞ্জিন
│   │   ├── database/
│   │   │   ├── schema.sql                <-- সম্পূর্ণ PostgreSQL / Supabase স্কিমা (RLS সহ ৫টি টেবিল)

│   │   ├── tests/

│   │   │   └── engines.test.ts           <-- গাণিতিক সূত্র ও এগ্রোনমিক নিয়মের ইউনিট টেস্ট

        │   ├── lib/api.ts                <-- ব্যাকএন্ড এপিআই ক্লায়েন্ট
```

## 🚀 কীভাবে চালাবেন (How to Run)

### ১. ব্যাকএন্ড সার্ভার চালানো (Backend Server)
```bash
# ব্যাকএন্ড ফোল্ডারে প্রবেশ করুন
cd backend

# প্যাকেজ ইনস্টল করুন
npm install

# ১. ইঞ্জিন ইউনিট টেস্ট চালান (৫/৫ পাস)
npm run test:engines

# ২. প্রি-ফ্লাইট ভেরিফিকেশন টেস্ট চালান (বগুড়া, ময়মনসিংহ, বরিশাল)
npm run test:preflight

# ৩. ব্যাকএন্ড সার্ভার চালু করুন (Port 5000)
npm run dev
# অথবা বিল্ড করে প্রোডাকশনে চালু করুন:
# npm run build && npm start
```

### ২. ফ্রন্টএন্ড অ্যাপ চালানো (Frontend App)
```bash
# ফ্রন্টএন্ড ফোল্ডারে প্রবেশ করুন
cd interactive-map-studio-main/interactive-map-studio-main

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
# ব্রাউজারে খুলুন: http://localhost:3000 (বা প্রদর্শিত পোর্টে)
```

## 🛰️ ৪টি কোর ইন্টেলিজেন্স ইঞ্জিন (Core Intelligence Engines)

1. **ইঞ্জিন ১ (MCDA Crop Recommendation - XAI):**
   - মাটির পিএইচ (৬.০ - ৭.৫), মাটির বুনট (USDA Texture Triangle), মূলমণ্ডল আর্দ্রতা এবং নাসা GDD বিশ্লেষণ।
   - শতভাগ দ্বিভাষিক (বাংলা ও ইংরেজি) ব্যাখ্যামূলক কারণ ("কেন এই ফসল উপযুক্ত?") এবং ঝুঁকি বিশ্লেষণ।
2. **ইঞ্জিন ২ (Soil Nitrogen & Crop Rotation):**
   - ডালজাতীয় ফসলের মাধ্যমে $+40\text{ to }+65\text{ kg N/ha}$ সংযোজন এবং ধান/ভুট্টার পুষ্টি শোষণ ব্যালেন্স।
   - পরপর একই পরিবারের ফসল (যেমন সোলাফেসি: আলু $\rightarrow$ টমেটো) চাষের রোগ বিস্তার রোধে সতর্কবার্তা।
3. **ইঞ্জিন ৩ (Climate Hazard Early Warning):**
   - ধানের পরাগায়নে ৩৫°C-এর বেশি তাপপ্রবাহে চিটা হওয়ার (Spikelet Sterility) ঝুঁকি শনাক্তকরণ।
   - ৩ দিনের বৃষ্টি $> 110\text{mm}$ বা মাটির স্যাচুরেশন $> 90\%$ হলে জলাবদ্ধতার ড্রেনেজ সতর্কবার্তা।
   - শিকড়ে আর্দ্রতা $\le 18\%$ হলে খরা সতর্কতা এবং উচ্চ আর্দ্রতায় (>৮৫%) ব্লাস্ট/ধসা রোগ পূর্বাভাস।
4. **ইঞ্জিন ৪ (Counterfactual Audit: With vs Without NASA Data):**
   - নাসা উপগ্রহ তথ্য ছাড়া কৃষকের সনাতন চাষের অপচয় (~ ৳৪,৮০০/একর) বনাম নাসা তথ্যের নির্ভুল সেচ ও পরিচর্যায় জ্বালানি ও সার বাবদ ৩,০০০ – ৫,০০০ টাকা সাশ্রয় এবং ১৫.৪% ফলন বৃদ্ধির তুলনামূলক অডিট।
